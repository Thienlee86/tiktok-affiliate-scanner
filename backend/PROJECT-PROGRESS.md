# Project progress model

Progress is weighted by production value, not file count.

- Frontend/PWA foundation: 15% — done
- Backend scanner pipeline: 20% — done
- Revenue engine: 10% — done
- Security/health/alerts: 10% — done
- TikTok Partner review: 10% — waiting on TikTok
- Creator OAuth + first live API call: 15% — blocked by approval
- Durable storage + production cron: 10% — prepared, provider not selected
- Dashboard live-data wiring: 5% — prepared
- First attributable revenue validation: 5% — blocked until live path exists

Prepared work receives half credit because architecture/code exists but production integration is not yet proven. Current evidence-weighted completion: 63%.

This percentage must not be interpreted as 63% of the time-to-first-revenue: external TikTok review latency is outside engineering control.
